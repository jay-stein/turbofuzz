# 2026-10-03 — Loader UX: smart URLs, dropzone, disclaimer

## Changes

- **One URL field** replaces "Load URL" + "Scrape table". The button label
  updates as you type (`Load file` for `.csv/.tsv/.psv/.txt`, else
  `Scrape table`) and the actual behaviour is decided after download:
  content-type `csv` / `tab-separated` / `comma-separated` -> data; `html` ->
  scrape first table; otherwise the URL extension decides. Enter in the field
  submits.
- **Globe icon** inside the field makes the web-link capability obvious.
- **Dropzone**: a dashed drag-and-drop target with an upload icon ("Drop a
  CSV / TSV / PSV here — or click to browse"). Drops anywhere on the card are
  captured for files (text drops in the textarea still work), with a dragging
  highlight. Click or keyboard (Enter/Space) opens the file picker.
- **Paste flow clarity**: the primary button is now "Load pasted data",
  sitting with the delimiter/header controls directly under the textarea.
- **Disclaimer always visible** under the URL input: review `robots.txt`,
  Terms of Service and licensing; respect server load limits; comply with
  data privacy laws.
- Subtitle now names all three input methods.

## Notes

- `/api/fetch` (the CORS proxy) only exists on the deployed Worker, as before.
- Dropzone accepts any file; encoding detection (UTF-8 / windows-1252) is
  unchanged.
