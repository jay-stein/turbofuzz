## Decisions

- Locale ties fall back to delimiter/encoding prior (`;` or windows-1252 →
  decimal comma); comma thousands grouping (1,234,567) votes English so the
  legacy cp1252 test stays correct.
- Export always writes typed values for numeric/date columns (unparseable
  cells blank); the "Blank nulls" checkbox controls text columns.
- Clean/transform draws from the untouched source each time, so merge ops are
  appended to existing clean steps rather than replacing them.
- Transform previews recompute the pipeline in the worker on each step change
  (same cost as Apply); clean previews count changed cells against source.
- Suggestion chips only show conservative, actionable patterns; sentinels must
  be far from the column median to avoid flagging ordinary `-1` values.
- Only the last transform step is undoable individually (column indexes make
  middle removals unsafe); clean steps are independently removable/reorderable.
- `date parts → date` (combine year/month/day) was not implemented; the
  single-column "convert to date" suggestion covers the common case.
