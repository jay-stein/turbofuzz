# Claude Prompt — Review One Implemented Change

You are reviewing a single completed UX/code change in a browser-based data application. Do not make code changes.

## Inputs
- Approved change brief:
- Before Git commit / baseline:
- After Git commit:
- Relevant screenshots or browser URL:
- Test results:

## Tasks
1. Compare the implementation with the approved brief and acceptance criteria.
2. Check the actual changed workflow in the running app if access is available.
3. Inspect the diff or change summary if available.
4. Check that existing features and entry points listed under “Must preserve” still work and remain discoverable.
5. Check relevant empty, loading, error, success, keyboard and responsive states.
6. Identify unintended scope expansion or visual inconsistency.

## Report only actionable findings
For each finding include:
- Severity P1–P4.
- Observed evidence and reproduction steps.
- Acceptance criterion or preserved behaviour violated.
- User impact.
- Confidence.
- Smallest corrective action.

Separate:
- Confirmed regression.
- Acceptance criterion not met.
- Risk that needs more testing.
- Optional polish.

Do not reopen unrelated design questions or propose a fresh redesign. If the change meets the brief and no material regression is evidenced, say so. Clearly state what could not be tested.
